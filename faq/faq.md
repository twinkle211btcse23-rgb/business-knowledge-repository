# Frequently Asked Questions

### 1. What is the purpose of this system?

The system is designed to manage online shopping operations including products, customers, orders, payments, and inventory.

### 2. Who can use the system?

The system can be used by customers and administrators.

### 3. Can administrators manage products?

Yes. Administrators can add, update, and remove products.

### 4. Can customers track orders?

Yes. Customers can view their orders and track their order status.

### 5. How is product inventory maintained?

The inventory quantity is updated when products are added, sold, or restocked.

### 6. Why is GitHub used for this repository?

GitHub provides cloud-based storage, version control, collaboration, and public accessibility for the knowledge repository.
