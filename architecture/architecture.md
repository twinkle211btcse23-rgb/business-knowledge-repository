# System Architecture

## Architecture Overview

The E-Commerce Management System follows a three-layer architecture.

```text
        Customer / Admin
               |
               v
       Frontend Application
               |
               v
       Backend / REST APIs
               |
               v
           Database
```

## 1. Presentation Layer

The presentation layer provides the user interface through which customers and administrators interact with the system.

## 2. Application Layer

The application layer contains the business logic and REST APIs responsible for processing requests.

Main responsibilities:

* Authentication
* Product management
* Order processing
* Cart management
* Payment processing
* Inventory management

## 3. Database Layer

The database layer stores information about:

* Users
* Products
* Categories
* Orders
* Order Items
* Payments
* Inventory
