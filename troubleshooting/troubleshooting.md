# Troubleshooting Guide

## 1. Unable to Login

**Possible Cause:** Incorrect email or password.

**Solution:** Verify the login credentials and try again.

## 2. Product Not Available

**Possible Cause:** Product quantity is zero.

**Solution:** Check inventory and update the product quantity.

## 3. Order Cannot Be Placed

**Possible Cause:** Product is out of stock or required information is missing.

**Solution:** Check product availability and verify the order details.

## 4. API Not Responding

**Possible Cause:** Backend server may not be running.

**Solution:** Start the backend server and verify the API endpoint.

## 5. Database Connection Error

**Possible Cause:** Incorrect database configuration or unavailable database server.

**Solution:** Verify the database connection settings and database status.
