# User Guide

## Customer

### Step 1: Registration

Create an account by providing your name, email address, and password.

### Step 2: Login

Log into the application using the registered credentials.

### Step 3: Browse Products

Browse available products and use the search functionality to find specific products.

### Step 4: Add to Cart

Select a product and add it to the shopping cart.

### Step 5: Place Order

Review the cart and provide the required delivery and payment information.

### Step 6: Track Order

Open the order history section to view the current status of an order.

## Administrator

Administrators can:

* Add or remove products.
* Update product information.
* Manage inventory.
* View customer orders.
* Update order status.
* Manage users.
